# Project Abstract: SmartTriage Dashboard

The SmartTriage Dashboard is an advanced AI-integrated healthcare management system designed to streamline emergency response and patient care across district-wide health centers. It features a "Dual-Brain" risk assessment model that analyzes patient vitals to provide real-time triage, coupled with a sophisticated GPS-enabled ambulance dispatch and tracking system. The platform offers dedicated portals for patients, doctors, PHC nurses, and DDHS administrators, drivers ,ensuring seamless communication and coordination during critical events. By utilizing live navigation via Leaflet Routing Machine, it provides real-road tracking for ambulance drivers to minimize response times. This unified ecosystem enhances healthcare accessibility, optimizes resource allocation, and ensures that emergency cases are handled with the highest level of efficiency and technical precision.
